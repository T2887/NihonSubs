# 日文字幕生成器（NihonSubs · 安卓版）使用说明

手机本地跑的离线字幕工具：**视频 / 音频 → 日文转写 → 中文翻译 → SRT 字幕**。
全程不联网，不上传任何内容。

---

## 一、装什么

只有一个文件：`asmr-mobile.apk`（约 58 MB）

- 系统要求：**Android 10 及以上**（`minSdk 29`），arm64 手机
- 装好后第一次打开会解压运行文件，约几秒

---

## 二、第一次用：放模型

因为模型太大（1.35 GB）没法塞进 APK，需要手动放一次。

### 方法 A：用数据线拷（推荐，快）

把两个文件拷到手机这个目录：

```
Android/data/com.nihonsubs/files/models/
```

需要的两个文件：

| 文件名 | 大小 | 作用 |
|---|---|---|
| `model.int8.onnx` | 230 MB | 日语语音识别（SenseVoice） |
| `hy.gguf` | 1.1 GB | 日语→中文翻译（Hy-MT2-1.8B） |

### 方法 B：在 App 里导入

点「导入模型」，选文件即可。支持两种方式：

- 选**单个文件**（一次一个，`model.int8.onnx` 和 `hy.gguf` 各选一次）
- 选**打包好的 zip**（两个文件在压缩包根目录，一次搞定）

### 模型从哪来

两个模型都打包在 **`ASMR安卓版模型.zip`**（1.35 GB）里，解压出两个文件直接放进 `models` 目录即可：

```
ASMR安卓版模型.zip
├── model.int8.onnx    230 MB   语音识别
└── hy.gguf            1.1 GB   翻译
```

> `hy.gguf` 就是 PC 版发布目录里的 `Hy-MT2-1.8B-Q4_K_M.gguf`（改名成 `hy.gguf`）。
> `model.int8.onnx` 是从 PC 版的 `model/SenseVoiceSmall`（PyTorch 格式）导出的 ONNX int8 版本，
> 手机跑不了 PyTorch，必须用这个 ONNX 版。

---

## 三、放片子

### 方法 A：App 里选

点「添加文件」，选视频或音频。支持：

- 视频：mp4 / mkv / avi / mov / wmv / flv / webm / m4v / ts / mpg / mpeg
- 音频：flac / wav / mp3 / m4a / aac / ogg / opus / wma

### 方法 B：拷进目录

```
Android/data/com.nihonsubs/files/input/
```

重开 App 会自动扫出来。

---

## 四、开始处理

点「开始处理」，四步全自动：

| 步骤 | 做什么 |
|---|---|
| 1/4 提取音频 | ffmpeg 抽出 16 kHz 单声道 |
| 2/4 起翻译服务 | 加载 Hy-MT2 模型（约 5 秒） |
| 3/4 语音识别 | SenseVoice 转写日文，带时间轴 |
| 4/4 翻译写字幕 | 逐句翻译并生成 SRT |

**切到别的 App 也会继续跑**，因为开了前台服务。进度看通知栏。

想中止就点「停止」。

---

## 五、拿字幕

处理完的字幕在：

```
Android/data/com.nihonsubs/files/output/
```

每个片子生成一个 `<原文件名>.chs.srt`。
和视频放在一起，用任何播放器加载字幕即可。

## 六、耗时参考

测试机：Redmi K30U（天玑 1000+，8 核）

| 片子时长 | 处理耗时 |
|---|---|
| 90 秒 | 约 31 秒 |
| 16 分钟 | 约 6~7 分钟 |
| 91 分钟 | 约 12 分钟 |

换更好的手机（如天玑 9200+）大约快 2 倍。

## 七、常见问题

**Q：字幕条数很少？**
ASMR 片子环境音多，纯音效段（喘息、水声、BGM）会被 VAD 跳过，这是正常的。
有明确人声的部分都能识别出来。

**Q：识别/翻译准确度比不上 PC 版？**
手机用的是 int8 量化模型（体积和速度的折中），比 PC 版的 float16 略逊。
另外手机端为了速度用了 CTC 架构的 SenseVoice，PC 全量模式用的是 faster-whisper，两条路线不同。

**Q：卡住不动？**
点「停止」，再点一次「开始处理」重来。
如果反复卡住，看下面的日志卡里退出码是多少。

**Q：日志显示「缺少模型」？**
回第二步，确认 `models` 目录下两个文件都在，文件名完全一致（区分大小写）。

**Q：能后台跑吗？**
能，最多 10 分钟（Android 对 `dataSync` 类型前台服务的限制）。
更长的片子建议放前台等它跑完。

**Q：会联网吗？**
不会。APK 里虽然声明了 INTERNET 权限（llama-server 用 `127.0.0.1` 本地回环），
但没有任何外部网络请求。

## 八、和 PC 版的区别

| | PC 版（兼容模式） | 安卓版 |
|---|---|---|
| 识别 | SenseVoiceSmall（PyTorch） | SenseVoiceSmall（ONNX int8） |
| 翻译 | Hy-MT2-1.8B Q4_K_M | 同款模型 |
| 音频提取 | ffmpeg | ffmpeg（arm64 静态版） |
| 字幕整理 | Rust | Rust（复用同一份逻辑） |
| 速度 | 16 分钟片子约 3 分钟 | 16 分钟片子约 6~7 分钟 |
